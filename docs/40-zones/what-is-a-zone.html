Zones

What a zone is

A zone is a shape in the world plus a set of properties, and those two halves live in two different programs.

This page is outline. It may be incomplete or unverified. Anything marked unverified has not been proven in a running game.

Read this before the other zone pages. A zone is two things that get edited separately, and understanding the split makes everything else obvious.

Planned for this page:

  • the shape is an object you place in the map editor, and it carries an Id
  • the behaviour is a set of properties you attach in the zone settings tool
  • the two are matched by that Id, character for character. This is where most zone problems actually come from
  • one zone can carry several properties at once. A deploy zone that is also a store is a single zone with two properties
  • the full list of property types, and which page covers each
