Appendix B - specialists

Every specialist

The six specialist classes and all 25 shipped specialists, with their costs and abilities, read from the game's own data.

Every specialist#

The game ships 25 specialists in six classes. This appendix lists them all, with the exact values the game uses, so you can copy what works and beat it on purpose. To make your own, start with Custom specialists.

  • Descriptor settings: every field of a specialist file.
  • Every ability: all 47 modifier types, their fields, and which shipped specialists carry them.

Every number here was read from the game: the specialists from initial.cache_block inside preload/paks/client/initial.pak, the names and class descriptions from the game’s English strings, and the fields from the editor’s type definitions.

The six classes#

The class is the tab a specialist is listed under. The saved file stores the number in the first column. It decides nothing else: any class can carry any ability.

speciality Class Schema name Shipped The game’s description
0 Mechanic MECHANIC 5 Mechanics keep the trucks running throughout the expeditions and improve the effectiveness of anchors
1 Logistician LOGISTICS_SPECIALIST 4 Logistics reduce the cost of deploy and allow you to use binoculars more efficiently
2 Hydrologist HYDROLOGIST 4 Hydrologists open access to special equipment and help the engine run longer underwater
3 Jaeger JAEGER 4 Jaegers are real experts in survival in extreme conditions; they find paths and pave new ones
4 Operator OPERATOR 4 Operators open access to the drone and help to use it more efficiently
5 Manager MANAGER 4 Managers help to earn more money for completing expeditions, can increase the amount of prepayment

6 is NONE. Saber documents that it crashes the game. Never use it.

Spelling

Saber’s guide writes LOGISTIC_SPECIALIST. The editor schema and the game’s own data say LOGISTICS_SPECIALIST; the game calls the class Logistician on screen.
