Appendix B - specialists

Every ability

All 47 specialist modifier types: what each does, every field with its type and default, and the shipped specialists that carry it.

Every ability#

The engine defines 47 modifier types. In a descriptor each is written as SpecialistModifier plus the name below. Field names must be copied exactly, misspellings included (Consumpion, Suspencion, Inceased, Guaranted); a correctly spelled field is ignored.

Each type also has a label field for every value (the field name plus UiDesc). Those control the text on the card, and any ability may also carry overrideUiDesc to replace its card line with your own text. Both are covered under When an ability never appears on the card.

Types and defaults are from the editor’s type definitions. “Shipped values” lists every vanilla specialist that carries the ability.
