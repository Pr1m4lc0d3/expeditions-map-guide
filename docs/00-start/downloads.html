Downloads

Every tool, template and pack this guide mentions, in one place, with what each one is for and where to get it.

Everything here is free. The tools are open source under the MIT licence; the packs are on mod.io. Not affiliated with or endorsed by Saber Interactive.

Read a tool’s README before you run it

Most tools report what they would change and only write when you ask. Close the game and the editor first, and back up your map the first time a tool edits it.

Tools#

All in one repository, expeditions-tools, except the two at the end, which have their own. Download it with Code > Download ZIP, or git clone, and keep its folders side by side. Each folder’s README says what it needs.

Tool What it is for Get it
Map tools Building and fixing maps from the command line: objectives and story chains from one plan file, earning a custom truck and its parts, gateways and regions, the fix to run after every pack, packing checks, real-world terrain, roads, rivers and placed models map-tools
Map model tools Your own 3D models on a map: one command from a .glb to a model you can place map-models
Overlay tools Your own roads, fences and guardrails: pictures for the editor’s library, and the fix that lets the editor show them overlay-tools
FOB module tools Custom base modules: stats, recolours or your own building, with the descriptor, art and packing fob-modules
Rock lights A five-colour rock-light kit on any truck: your own truck in Media, or on your own PC an installed truck mod. Places the pods on the truck’s own frame rock-lights
Engine ghost Puts a truck’s see-through start-up engine in its engine bay: reads the truck’s own mesh, finds the bay, draws a picture and writes the place into an installed mod or a Media project engine-ghost
Vehicle importer Porting SnowRunner trucks: textures, bumpers, tyres, artwork and sound. For your own game only expeditions-vehicle-importer
Specialist builder Custom specialists: portraits, abilities, balance and publishing expeditions-specialist

The AI tools page lists every command in these folders by task.
