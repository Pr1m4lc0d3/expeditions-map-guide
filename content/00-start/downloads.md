Everything here is free. The tools are open source under the MIT licence; the packs are on
mod.io. Not affiliated with or endorsed by Saber Interactive.

!!! note "Read a tool's README before you run it"
    Most tools report what they would change and only write when you ask. Close the game
    and the editor first, and back up your map the first time a tool edits it.

## Tools

All in one repository, [expeditions-tools](https://github.com/Pr1m4lc0d3/expeditions-tools),
except the two at the end, which have their own. Download it with **Code > Download ZIP**,
or `git clone`, and keep its folders side by side. Each folder's README says what it needs.

| Tool | What it is for | Get it |
|---|---|---|
| **Map tools** | Building and fixing maps from the command line: objectives and story chains from one plan file, [earning a custom truck and its parts](../50-missions/vehicle-unlocks.html), [gateways and regions](../40-zones/gateways.html), the fix to run after every pack, packing checks, real-world terrain, roads, rivers and placed models | [map-tools](https://github.com/Pr1m4lc0d3/expeditions-tools/tree/main/map-tools) |
| **Map model tools** | [Your own 3D models on a map](../30-dressing/making-models.html): one command from a `.glb` to a model you can place | [map-models](https://github.com/Pr1m4lc0d3/expeditions-tools/tree/main/map-models) |
| **FOB module tools** | [Custom base modules](../60-custom/fob-modules.html): stats, recolours or your own building, with the descriptor, art and packing | [fob-modules](https://github.com/Pr1m4lc0d3/expeditions-tools/tree/main/fob-modules) |
| **Rock lights** | [A five-colour rock-light kit on any truck](../65-vehicles/rock-lights.html): your own truck in Media, or on your own PC an installed truck mod. Places the pods on the truck's own frame | [rock-lights](https://github.com/Pr1m4lc0d3/expeditions-tools/tree/main/rock-lights) |
| **Vehicle importer** | [Porting SnowRunner trucks](../65-vehicles/porting-a-truck.html): textures, bumpers, tyres, artwork and sound. For your own game only | [expeditions-vehicle-importer](https://github.com/Pr1m4lc0d3/expeditions-vehicle-importer) |
| **Specialist builder** | [Custom specialists](../60-custom/specialists.html): portraits, abilities, balance and publishing | [expeditions-specialist](https://github.com/Pr1m4lc0d3/expeditions-specialist) |

The [AI tools](../80-ai-tools/toolkit.html) page lists every command in these folders by task.

## 3D models and road packs for your map

Each pack has a one-click installer, no Python needed, and comes with the map fix to run
after you pack a map that uses it.
