Planned for this page:

- placing and orienting objects, snapping, and grouping
- cliff and talus placement, and the fact that **a model set deep into a rock face is
  usually correct**. Bluff and talus pieces are intentionally sunk several metres. Only
  man-made objects should sit exactly on the surface
- custom models, and getting your own geometry in
- never put a backup file inside a folder the editor scans. It will be loaded as map
  content, and the symptom presents as a selection bug rather than as a stray file
