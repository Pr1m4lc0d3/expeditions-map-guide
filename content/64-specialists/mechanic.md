# Mechanics

`speciality`: `0` (`MECHANIC`)

The game describes the class as: "Mechanics keep the trucks running throughout the expeditions and improve the effectiveness of anchors"

The class decides only the tab. The abilities below are what these specialists happen to carry; a custom one in this class may carry any ability.
